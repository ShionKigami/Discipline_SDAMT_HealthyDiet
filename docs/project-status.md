Состояние ТЗ
Техническое задание повторно проверено. В ходе проверки и актуализации были исключены задачи, требования, варианты использования, системные компоненты, связанные с создание системы взаимодействия пользователей через социальную ленту и чаты, т.к. они не обязательны для корректного выполнения основных задач мини-проекта (помощь в ведении правильного питания) и были добавлены с целью выполнения требований по объёму ранних лабораторных работ (фантазии на лучшее не хватило). Под вопросом создание полноценного сайта в пунте о процессе внедрения, т.к. это дополнительный объём работы для мини-проекта, не влияющий на его реализацию. Также в пункте «Технические детали» были пересмотрены выбранные технологии и инструменты для реализации мини-проекта: 
•	для клиентской части и локальных расчётов: React Native + TipeScript (или JavaScript)
•	для бэкенда: Node.js или Python (изучить и решить, что лучше и понятнее)
•	серверная база данных: PostgreSQL
•	локальная база данных: WatermelonDB (SQLite)
•	для облака: Supabase (PosrgreSQL)
•	архитектура не меняется.
